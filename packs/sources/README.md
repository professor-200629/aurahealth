# Guidance source packs

Each guidance card is a JSON file here, with:

- `id`, `region`, `language`
- `title` and `text`: short and **verbatim** from the source, never paraphrased in a way that changes the meaning
- `source`: title, URL, publisher, date checked
- `license`: the reuse terms, and the evidence that bundling is allowed
- `review`: who checked that the text matches the source and suits this use (a translator and a clinician for anything safety-related)

**There are no cards in this prototype.** For India, no authoritative medical guidance was found that both allows
bundling and has been reviewed for this use. For example, the Ministry of Home Affairs website policy does not allow
reproducing its content without permission. AuraHealth therefore shows an honest "cannot assess this situation"
message and the emergency number instead of invented guidance.
